There were so many challenges throughout this project. I think figuring out how the local storage was implemented was the one of the tougher parts because I had to look through a lot of documentation on MDN and other sites to get a grasp of how it works. Eventually, I watched a video of someone explaining it in laymen's terms so I could understand. Additionally, working with the DOM manipulation is still a really difficult concept to wrap my mind around. This assignment helped with understanding it a little more but there's still a lot of room for growth. Utilizing the table property was new for me and as such, I had a little trouble styling it. I also, implemented three or four different ways to parse/loop through a set of arrays ( filter(), find(), forEach() and for..of ) without using the standard for loop setup. I'm proud of myself for implementing these alternatives because I am a creature of habit, meaning, I like to use the tools I'm very comfortable with and not branch out and utilize tools that oftentimes, is better. Finally, I feel like the logic needed for these functions required me to really think and test out my written code and figure out why it would work or not work. This was maybe the second largest blocker for me but i eventually worked through it. I was forced to break down the functions line by line to get them to work as intended. Also, using console logs everywhere kept me honest and focused on outputs throughout the project. I think i could have improved some of the looping functions to find the best situtation for each type given more time. This project was really tough and showed me where my lapses in knowledge and practice are. I will build upon this project to get stronger.
